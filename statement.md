# Project Statement: Student Performance & Ranking Analyzer

## Problem Statement
Educational institutions often require customized, lightweight tools to evaluate student performance, rank academic standing, and isolate top/bottom performers without the overhead of heavy enterprise databases.

## Scope of the Project
This project implements a command-line interface (CLI) application in Python using fundamental algorithms (Units 1, 2, 3, and 5 syllabus) to record student scores, filter out duplicate records, compute totals, and rank performance using partitioning techniques.

## Target Users
* Course Instructors
* Academic Tutors
* School Department Administrators

## High-Level Features
1. Student Record Management with duplicate ID prevention using Set operations.
2. Analytics Engine implementing custom summation, maximum finding, and K-th smallest partitioning algorithms.
3. Class Leaderboard Reporting utilizing order-reversal array techniques.
