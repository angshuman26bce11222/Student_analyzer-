# Student Performance & Ranking Analyzer

## Overview
A Python-based academic management tool applying fundamental algorithms, array techniques, and modular program design.

## Features
* **Record Management**: Add and maintain student records using dictionaries and sets.
* **Analytics Engine**: Algorithm implementations for finding max scores, custom summation, and K-th smallest values via partitioning.
* **Reporting**: Order-reversal ranking outputs and tabular formatting.

## Technologies Used
* Language: Python 3.x
* Version Control: Git & GitHub
* IDE: Visual Studio Code
